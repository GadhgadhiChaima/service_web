# Système de Feedback - Web Service GraphQL

## Description
Ce projet est un système de feedback permettant à des utilisateurs d’évaluer des produits numériques via une API GraphQL.

## Technologies
- Node.js
- Express
- GraphQL
- JWT (authentification)
- Base de données en mémoire (ou SQLite)

## Installation
bash
git clone <repo>
cd projet-feedback
npm install
npm start
